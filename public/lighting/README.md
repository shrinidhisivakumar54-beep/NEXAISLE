# Lighting collection

Original manufacturer images of real IKEA product designs, retrieved 2026-10-29. Product names and images © Inter IKEA Systems B.V. Each fixture has a visible link to its source page. This is a reference collection for a local demonstration, not a live retailer or an IKEA partnership.

Image files are the original downloaded JPEGs, not generated lighting models or AI-generated product imagery. CSS layers illustrate switching, ambient day/night conditions and colour temperature. These effects are not measurements or manufacturer performance claims. Fixed-colour bulbs retain their published 2700 K or 4000 K setting. The intensity slider affects only the preview and makes no claim that a product is dimmable. No price or stock data is asserted.

See sources.json for source URLs and asset provenance.
