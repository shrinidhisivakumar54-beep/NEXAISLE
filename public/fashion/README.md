# NEXAISLE editorial imagery

`collection-atlas.png` is an original AI-generated set of photographic-style garment cutouts made for this NEXAISLE concept. It does not depict verified physical inventory or another brand's catalogue. There are no third-party logos.

The original 1536 × 1024 transparent PNG is shipped intact. `src/fashion/collection.ts` records each piece's pixel bounds; Three.js UV offsets and CSS positioning display the relevant region without runtime image processing or external image hosts.

The showroom is a hybrid 2.5D/3D presentation: alpha-cutout clothing plus real 3D wooden hangers, metal hooks, a chrome rail, lighting and shadows. Only front imagery exists. The inspector deliberately limits rotation to avoid claiming an accurate back view, volumetric garment model or fit simulation. Each demo garment currently has one photographed-style colourway.
