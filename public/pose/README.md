Local MediaPipe Pose runtime and lite model from the pinned npm package @mediapipe/pose 0.5.1675469404, published by Google. Runtime/model files are copied unchanged from the package (Apache-2.0, as declared in its package metadata). They are served locally so personal camera frames and photos are not transmitted for inference. Only the lite landmark model is included; full/heavy models are not used. This estimates landmarks, not garment draping or clothing fit.
