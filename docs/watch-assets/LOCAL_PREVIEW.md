# Local PRX preview

The supplied PRX GLB is excluded from GitHub because the user authorised local preview only.

To restore locally, copy the supplied `Tissot PRX.glb` to:
`public/models/watches/tissot/prx-powermatic-80/watch.glb`
Then set `VITE_LOCAL_PRX_PREVIEW=true` in your local `.env` and restart Vite.

The default is false, so a checkout can run without this file. The other three watches remain procedural prototypes. The source includes runtime separation of the PRX's existing exterior geometry into 11 assemblies; no internal movement is added. Commercial-use permission for the supplied asset remains unconfirmed. Do not publish the asset without resolving that permission.

The Desktop ZIP includes the local file and local settings. It is a local backup, not a redistributable release.
